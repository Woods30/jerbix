# 写第一条更新日志

更新日志条目放在 `content/changelog/`，一次发布一个 Markdown 文件。与博客不同，
它没有单篇页面：所有条目都渲染在同一个更新日志页面上，最新的在最前。

| 字段 | 必填 | 含义 |
|---|---|---|
| `title` | 是 | 这次发布的标题，作为条目标题 |
| `date` | 是 | ISO 时间戳；条目按它倒序排列，最新的在前 |
| `summary` | 是 | 一句话描述，显示在标题下方 |
| `locale` | 否 | `en` 或 `zh`；不写时按文件名后缀判断 |

文件名不参与 URL，但建议仍按时间排序命名：`2026-11-02-release.md` 比 `release-2.md`
在目录列表里更好读。
